# 🏢 ระบบจัดการหอพักและค่าน้ำค่าไฟ (Dormitory Management System)
### Progressive Web App (PWA) | รองรับสมาร์ตโฟน (Mobile), iPad / แท็บเล็ต, และคอมพิวเตอร์ (PC)
**ฐานข้อมูล Google Sheets + พื้นที่จัดเก็บสลิปบน Google Drive (ฟรี 100%)**

---

## 📱 1. จุดเด่นการใช้งานบนแต่ละอุปกรณ์ (Multi-Device Responsive)

### 📲 บนมือถือ (Smartphones: iPhone / Android):
- **แถบเมนูด้านล่าง (Bottom App Bar):** สลับหน้าได้ง่ายด้วยนิ้วโป้งมือเดียว (ภาพรวม, ห้องพัก, จดมิเตอร์, บิล, เมนูอื่นๆ)
- **โหมดเดินจดมิเตอร์ทีละห้อง (Walk-and-Record Mode):** 
  - ออกแบบสำหรับการถือโทรศัพท์เดินจดตามหน้าห้องจริง
  - ตัวเลขและช่องกรอกขนาดใหญ่ สบายตา ไม่ต้องเพ่ง ไม่ต้องเลื่อนตารางไปมา
  - คำนวณหน่วยใช้สดๆ พร้อมแจ้งเตือนกรอบสีแดงหากเลขอ่านครั้งนี้น้อยกว่าครั้งก่อน
  - ปุ่ม **"💾 บันทึก & ไปห้องถัดไป ➡️"** ขนาดใหญ่ แตะครั้งเดียวกดบันทึกและเลื่อนไปห้องต่อไปได้ทันที
  - มีปุ่ม **🔦 ไฟฉายมือถือ** ในตัว ช่วยส่องมิเตอร์ในที่มืด ใต้บันได หรือตู้ควบคุมไฟ
- **ส่งบิลเข้า LINE ในคลิกเดียว:** มีปุ่ม **"📲 แชร์บิลส่ง LINE"** เรียกใช้ Web Share API ของโทรศัพท์ หรือคัดลอกข้อความสรุปยอดเงินพร้อมสแกน QR ไปวางในแชต LINE ให้ผู้เช่าได้ทันที
- **แนบสลิปง่าย:** กดถ่ายรูปจากกล้องมือถือเพื่อแนบรูปสลิปได้สดๆ ทันที
- **ป้องกันปัญหาแป้นพิมพ์และหน้าจอ:** ฟอนต์ขนาด 16px มาตรฐาน ไม่ทำให้ Safari/Chrome ซูมหน้าจอจนเสียรูปทรง

### 📱 บน iPad / แท็บเล็ต (Tablet):
- รองรับทั้งการใช้งานแนวตั้ง (Portrait) และแนวนอน (Landscape)
- การ์ดห้องพักและสถิติจัดวาง 2-3 คอลัมน์ อ่านง่ายเต็มตา
- สลับมุมมองจดมิเตอร์ได้ทั้งแบบ **ตารางรวม** หรือ **เดินจดทีละห้อง**
- ตัวกรองค้นหาแบบเรียลไทม์แตะใช้งานสะดวกด้วยระบบสัมผัส

### 💻 บนคอมพิวเตอร์ (Desktop / Laptop):
- เมนูด้านบน (Top Navbar) กว้างขวาง ครบทุกฟังก์ชัน
- แสดงตารางข้อมูลความละเอียดสูง พร้อมการส่งออก/นำเข้าไฟล์ CSV ภาษาไทย 100% (UTF-8 BOM)
- สั่งพิมพ์ใบแจ้งหนี้ / ใบเสร็จรับเงิน หรือ Save as PDF ได้พอดีกับกระดาษมาตรฐาน A4

## 📲 2. วิธีติดตั้งเป็นแอปบนหน้าจอโฮม (PWA Installation)

สามารถติดตั้งระบบนี้ไว้บนหน้าจอเสมือนเป็นแอปพลิเคชันจริงได้ โดยไม่ต้องดาวน์โหลดผ่าน App Store หรือ Play Store:

### สำหรับ iPhone และ iPad (Safari):
1. เปิดเว็บเบราว์เซอร์ **Safari** แล้วเข้าไปที่ลิงก์ระบบ
2. แตะปุ่ม **แชร์ (Share)** 📤 ที่แถบเครื่องมือ
3. เลื่อนลงมาแตะที่ **"เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"** ➕
4. แตะ **"เพิ่ม (Add)"** ที่มุมขวาบน จะได้ไอคอนแอปบนหน้าจอ เปิดใช้งานเต็มจอ ไม่มีแถบ URL กวนใจ

### สำหรับ Android (Google Chrome):
1. เปิดเว็บด้วย **Google Chrome**
2. แตะปุ่มเมนู 3 จุด **⋮** ที่มุมขวาบน
3. แตะ **"ติดตั้งแอป (Install App)"** หรือ **"เพิ่มลงในหน้าจอหลัก"**
4. ยืนยันการติดตั้ง ไอคอนแอปจะปรากฏบนหน้ารวมแอปของโทรศัพท์ทันที

### สำหรับคอมพิวเตอร์ (Google Chrome / Microsoft Edge):
- คลิกที่ไอคอน **ติดตั้งแอป (Install App)** บริเวณขวาสุดของช่องพิมพ์ URL บนแถบเบราว์เซอร์

## 🚀 4. การเชื่อมต่อฐานข้อมูล Google Sheets

1. เปิดเว็บไปที่ **[https://sheets.new](https://sheets.new)** เพื่อสร้าง Google Sheet ใหม่
2. คลิก **ส่วนขยาย (Extensions)** ➡️ **Apps Script**
3. คัดลอกโค้ดทั้งหมดจากไฟล์ [Code.gs](file:///c:/xampp/htdocs/0002/Code.gs) ไปวางแทนที่โค้ดเดิม แล้วกดบันทึก
4. เลือกฟังก์ชัน **`initDatabase`** แล้วกดปุ่ม **เรียกใช้ (Run)** พร้อมยืนยันการอนุญาตสิทธิ์ เพื่อสร้าง 7 ตารางชีตอัตโนมัติ
5. กดปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy)** ➡️ **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - เลือกประเภท: **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** *(สำคัญ)*
6. คัดลอก **URL เว็บแอป (Web app URL)** นำมาวางที่เมนู **"ตั้งค่าระบบ"** ➡️ ในช่อง **"Google Apps Script Web App URL"** แล้วกด **"ทดสอบเชื่อมต่อ"**
